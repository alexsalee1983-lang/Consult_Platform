# 安全咨询 Agent 平台 · 三期开发计划

> 来源：`docs/4A架构设计.md` v4.0 第七节（负责人 11-18 同意）展开成工作项，2026-11-20 起草，**待负责人确认**。三期 11-30 后开工、12-31 关口；二期见 `docs/二期开发计划.md`，验收以本文件第五节为准。
> 无专家先行（决策记录 11-18）仍适用：开发线 1 空闲时先做三期设计和代码，11-30 后合并。

## 一、目标

主题：生产上线、打穿起步、Agent 收敛。

关口验收标准（4A 7.1）：

1. 生产环境运行
2. SOC 试点项目走完交付链
3. 四格（SOC、IRE × 银行、电力）行业包达到 L1
4. 8 个 Agent 上线，评测不退化
5. 异构评审生效（评审与生成不同模型家族，平台强制校验）
6. 指标精简版出数

退路（4A 7.4）：生产环境卡在渗透测试或法务时，三期在测试机验收，上线顺延，不阻塞四期；没有真实项目时，用虚拟客户走完并标明。

## 二、工作分解

编号接二期：A、B、C 续号，新增 E 调研、F 运营与治理、G 平台与部署。
