# 人工环节复查（二期 C5）

依据：二期开发计划第十二节“自动化优先原则”（2026-11-15，负责人定）。本文逐个列出一期、二期平台上要人来做的环节，分三类：

- **保留**：属于第十二节“保留人工”的五类之一（签字、客户数据、只有人知道的事、公司经验的认可、规则变更），不改。
- **可自动**：程序或 Agent 能做，列出改法。**都要经负责人同意后才排期**，本文不改任何代码。
- **已自动**：二期已经改掉或正在改的，列出来方便核对。

建议排期一栏：v1.2 指改动小、风险低，可以排进下一版；v2.0 指要配合 B11～B13 或另做设计。

## 四、负责人决定（2026-11-15，决策记录同日“人工环节复查的落地范围”）

1. P6、P8、P10（交付链自动发起、自动评审、门禁通过自动转待签署）：同意，排进 v1.2，见 #128。签署本身不变，仍由项目经理签。
2. O4～O6、O8（运维检查改由 worker 定时执行，加告警）：同意，排进 v1.2，见 C5 运维自动化 PR。O4 在 M5 已经完成。运维手册的月检表已相应缩短。
3. O7 超过 90 天未登录自动停用：同意，和第 2 条在同一个 PR。系统管理员账号不自动停用，只在用户页标出；系统管理员可以在用户页恢复被停用的账号。
4. K7 复审到期自动处理：跟 B11 一起做，等待决定事项 15 定了再排。
5. K6 季度核对清单自动抓官网：涉及联网，不做。
6. P16 经验回流预填：排在 v2.0，已实现（投料选填来源项目，删除确认页预填，PR 见 feat/p2-p16-flowback-prefill）。

改法落地时都遵守第十二节第 4、6 条：自动做出的决定要记下是哪条规则判的，审计不记原文；数据保护红线和资质边界不变。
