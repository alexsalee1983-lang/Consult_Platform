# 四期 B39 · 知识流水线扩到其余三格（SOC × 电力、IRE × 银行、IRE × 电力）

状态：**v0 测量方案、评测集与报告骨架**（开发线 2，#508，2026-11-27）。数字一栏待测试机首跑后回填；本机没有 Docker 与网关模型，未实测。
范围：只用公开资料和虚拟数据（虚拟客户 GRID-B 等），不涉及任何真实客户材料。验收口径：`docs/总体规划.md` 第七节 v4.0 验收第 2 条——流水线覆盖四格，自动发布率达到三期校准后的目标，编造条款号为 0。

## 一、方法（沿用 B22）

流水线六段、指标口径、计时口径与 `docs/验收/三期-B22流水线实测.md` 第一、二节完全一致，本文只写三格不同的地方：

| 格 | 依据与行业知识（资料仓） | 装配评测集（资料仓 `eval/assembly/`） | 槽位 |
|---|---|---|---|
| SOC × 银行 | B22 首跑本身 | `soc-d4-d5-v0.yaml`（未写 industry，四格看板里算进 SOC 两格） | `products/soc.yaml`（C10） |
| SOC × 电力 | `drafts/ind/ind-power-*`、`industries/power.yaml` | `soc-power-d4-d5-v0.yaml`（8 章 37 条，industry: 电力） | `products/soc.yaml`（C10） |
| IRE × 银行 | `drafts/ire/*`、`drafts/ind/ind-bank-*`、`industries/bank.yaml` | `ire-bank-d4-d5-v0.yaml`（9 章 41 条，industry: 银行） | 评测集内 `slots:` 覆盖（v0） |
| IRE × 电力 | `drafts/ire/*`、`drafts/ind/ind-power-*`、`industries/power.yaml` | `ire-power-d4-d5-v0.yaml`（9 章 41 条，industry: 电力） | 评测集内 `slots:` 覆盖（v0） |

- 评测集写 `industry` 时，`kb-assembly-eval` 按立项同样的规则并入行业包（kb_tags、行业依据排在依据加权最前，与项目里 `kb.search` 一致，本 PR 补的），报告和 `--out` JSON 带行业，`--baseline` 不同行业的基线直接拒绝。
- IRE 产品配置还没有知识槽位，且 `products/ire.yaml` 正在 #475（C21①）里改：槽位草稿先写在评测集顶层 `slots:`（D4 九个、D5 七个，全部 `required: false`、`expert_review: pending`），专家勾选、#475 合并后再搬进产品配置（相当于 IRE 的 C10）。
- 依据类章节（就绪度目标 ≥95%）：SOC-D4-03（电力版换成电力监控系统安全防护规定、电力行业网络安全管理办法和电力黄金样例）、IRE-D4-05（两版各带行业依据 REF 两条和行业黄金样例一条）。
- 行业判断规则（B36 L2 草稿）挂在差距 / 根因章节：SOC-D4-02（电力）、IRE-D4-03（银行、电力）。B36 未发布前这些 key 会列为缺槽，属预期。

## 二、跑法（测试机，backend 容器内，一格一遍，攒成一批）

```bash
for s in soc-d4-d5-v0 soc-power-d4-d5-v0 ire-bank-d4-d5-v0 ire-power-d4-d5-v0; do
  python -m app.cli kb-assembly-eval /srv/knowledge/eval/assembly/$s.yaml --as <用户> --out /tmp/b39-$s-base.json > /tmp/b39-$s-base.txt
  python -m app.cli kb-assembly-eval /srv/knowledge/eval/assembly/$s.yaml --as <用户> --gate > /tmp/b39-$s-gate.txt
done
python -m app.cli indicators --v4 > /tmp/b39-v4.txt        # 四格分列：自动发布率、编造条款号、关键章节就绪度
python -m app.cli kb-ref-check  > /tmp/b39-refcheck.txt     # 发布条目条款号核对
python -m app.cli kb-basis-check > /tmp/b39-basis.txt       # 依据引用核对
```

采集、提炼、审核、候选各段命令同 B22 第一节表格；三格新增的采集只有电力监管公开资料（下发包，采集机白名单）。抽检按 B20 统计抽样与停止规则，人工计时同 B22。输出只落文件，回填只抄计数与比例。
