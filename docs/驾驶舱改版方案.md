# 项目驾驶舱与交付件页改版方案（四期）

> 2026-11-25 统筹会话与负责人讨论定稿；可点击示意见 `design/screens/07-驾驶舱改版示意.html`（虚拟客户 BANK-A）。
> 已定事项见 `docs/决策记录.md` 2026-11-25；未定事项见第九节，未确认前按“退路”开发。
> 工作项：A25、A26、A27、E3、F5（开发线 1），C21（开发线 2），登记见 `docs/工作项编号.md`。

## 一、为什么改

现在的驾驶舱一页塞了全景、证据、问卷、交付件、交付链、设置，顾问找不到下一步；调研包、客户自评、现场问答、答卷的前后关系在界面上看不出来；交付件页只有审阅，没有起草、修订、客户确认的完整回路。改版目标：

1. 一眼看到三件事：走到哪、该干什么、卡在哪。
2. 前后关系（流程）、包含关系（页面）、跳转关系（怎么去、怎么回）各一条规则，所有产品通用。
3. 按自动化优先（决策记录 2026-11-15）：平台默认自动，人只处理例外和必须担责的事。

## 二、包含关系：平台 → 项目 → 五个导航页 → 模块

项目内固定导航：**全景 | 输入 | 分析 | 输出 | 设置**。另有两个独立入口：调研助手（全屏，现场用）、交付件页（挂在“输出”下，路径 `项目 / 输出 / Dx`）。

| 页 | 模块 |
|---|---|
| 全景（即驾驶舱） | 页头：阶段、进度预测、自动化账本、本周简报、导出、交付链状态；行动条：下一步、待你处理、卡点、本周自动处理、调研进度；泳道全景图；“本周自动完成 N 项”折叠行 |
| 输入 | 调研（按受访角色，一行一份调研包）；资料需求清单（按产品配置）；证据库（资料 / 纪要 / 观察 / 客户系统统计摘要）；客户意见收件；严格档摘要卡 |
| 分析 | 事实确认单（答案池）；发现表（确认检查点）；成熟度初判、差距 TOP 5 |
| 输出 | 按阶段列 D1～D8 与阶段汇报 PPT；阶段包、项目交付包导出；影响面提示 |
| 设置 | 成员与写签分工；产品、档位、保留期；结项与删除 |
| 交付件页 | 四模式：① 起草 ② 评审与修订 ③ 定稿签署 ④ 客户确认；右侧页签：问题清单 / 写稿助手 / 客户意见 / 版本 |
| 调研助手 | 快速确认 → 议程 → 补问；实时矛盾提示；结束回传 |

## 三、全景图：按产品配置生成

- **列 = 产品阶段**，读 `products/*.yaml` 的 `stage:`：SOC、ISO、NSG 五段（启动、调研、分析、设计、验收），IRE、DSM 多一段“落地辅导”。交付链的步骤（如“第 3 步事实清单”）放在阶段里，不单独成列。
- **行 = 谁来做**：客户 / 顾问 / 项目经理 / AI·平台。AI 行取交付链步骤，顾问行取确认卡与检查点，项目经理行取签署，客户行取资料、自评、确认。
- 当前阶段展开成子段（如调研：场前 / 现场 / 离场 / 并行回路），已完成阶段折叠成一行，未来阶段只显示要做的事。
- 视图：全部 / 只看我的 / 只看例外 / 回放；今天线；产出行列出各阶段交付件与阶段包。
- 五个产品用同一套生成逻辑，验收时每个产品各立一个虚拟项目核对。

## 四、前后关系：一个项目从头到尾

| 阶段 | 顺序（人输入 / 平台 / 人确认签署 / 客户） |
|---|---|
| ① 启动 | 顾问填 D1 表单（预填）→ 程序成稿 → 立即评审 → 自动修订 → 项目经理签 D1 → 启动会、客户确认 → 启动阶段包（Word + PPT） |
| ② 调研 · 场前 | D2 表单 → 签 D2（定受访角色）→ 每角色生成调研包（选题 + 资料预填）→ 顾问一键发布 → 生成客户自评包 → 发出、交回、导入 → 比对生成现场议程 |
| ② 调研 · 现场 | 调研助手：快速确认（预填与自评已有答案，对方点头或改）→ 议程（矛盾、不清楚、开放题）→ 补问（需观察、需判断的题） |
| ② 调研 · 离场 | 答卷回传 → 答案池 → 事实确认单（自动确认 + 人确认例外）→ 第 3 步 → D3 → 门禁 0 问题时项目经理批量签 |
| ③ 分析 | 第 4 步差距分析 → 发现表（新检查点，自动确认 + 人确认低置信）→ 起草 D4（从第 7 步前移，待定）→ 评审修订 → 签 D4 → 分析汇报 PPT → 客户意见 → v1.1 |
| ④ 设计 | 起草 D5～D7（只引用已确认发现）→ 方案取舍卡 → 签署 → 客户审阅 |
| ⑤ 验收 | 起草 D8、终期汇报 PPT → 签 D8 → 客户确认 → 项目交付包 → 结项 → 保留期到期删除 |

贯穿各阶段的三条回路：

1. 签署人退回 → 自动变成问题条目 → 回到修订。
2. 客户意见 → 自动生成 v1.1 修订稿 → 评审修订 → 重签；v1.0 留存只读。
3. 上游变更（事实、发现、知识条目）→ 受影响交付件标“需更新” → 一键生成修订稿。

## 五、调研：四个渠道与一个答案池

**命名**：调研包 = 访谈前的题单（每个受访角色一份，顾问签名发布）；答卷 = 访谈后的回答。客户自评包、现场议程都从调研包派生。

每道题在调研包里标获取渠道：

| 渠道 | 时间 | 内容 | 来源标签 |
|---|---|---|---|
| 资料预填 | 场前 | 客户资料能回答的题，解析后自动填 | 客户资料 |
| 客户自评包 | 场前 | 客户能自答的封闭事实题，不含评分锚定 | 客户自评 |
| 现场题卡 | 现场 | 确认预填与自评答案；需要观察、演示的题 | 现场口述 / 现场证据 |
| 开放讨论 | 现场 | 议程：矛盾、“不清楚”、痛点、原因、期望 | 访谈纪要 |

**答案池**：按题号汇总，每条带来源和受访角色。可信度：现场证据 ＞ 客户资料 ＞ 现场口述 ＞ 客户自评。

- 一致 → 事实确认单 → 第 3 步 → D3。
- 矛盾 → 现场议程；访谈后仍未定 → 确认卡。
- 不清楚 → 资料需求清单 / 补证。

**时间线**：T-7 生成调研包、预填、拆出自评包并发出 → T-1～2 导入自评、比对、生成议程 → 现场约 10 分钟快速确认，其余时间谈议程 → 离场回传答卷进答案池。

**客户自评包**：

- 平台从调研包生成：单个加密离线网页（沿用现场工具技术：不联网、本机加密）+ Excel 模板兜底；随机口令只显示一次，另行告知客户。
- 顾问下载后用公司邮箱作附件发出；平台不对外发信，只记发出时间、截止日、版本并自动提醒。
- 客户填写（可续填）后导出加密答卷交回。导入入口：输入 → 调研 → 该角色行“客户自评”，或全景客户行“客户自评”节点。浏览器本机解密，口令不上传。
- 导入校验：包号与版本、完整性、机密级检测（`guard`）、重复导入。全部通过直接入池（11-25 已定）；未答过多、与资料大面积不一致、命中机密级时才弹预览让人确认；可撤销本次导入。
- Excel 按题号导入，表外内容列出由顾问决定；非文件答复由顾问在调研助手“代录客户自评”，注明依据。
- 严格档：在现场工具里导入，只回传摘要卡。审计只记包号、题数、命中类别，原文件不留存。

## 六、跳转关系

| 从 | 点什么 | 到哪（怎么回） |
|---|---|---|
| 全景 · 轻节点 | 确认卡、卡点（催办）、客户意见、客户自评、AI 步骤、阶段包 | 右侧抽屉就地办完；抽屉底部“查看全部”→ 对应子页面并自动筛选 |
| 全景 · 交付件节点、产出行 | D1～D8、签署、核对 | 交付件页 |
| 全景 · 调研节点 | 现场访谈 / 调研包 / 事实确认 | 调研助手 / 输入页调研区 / 分析页 |
| 任一子页面条目 | “⌖ 全景” | 回全景并闪烁高亮对应节点 |
| 行动条、我的任务 | 任一待办 | 直接到办事的地方，不绕路 |
| 调研助手 | 结束并回传 | 答案进答案池，跳分析页事实确认单；未定矛盾进全景确认卡 |
| 交付件页 | 问题条目“让助手改写”、选中文字 | 同页写稿助手页签，建议以修订痕迹插入 |

## 七、自动化分工

| 环节 | 平台自动 | 人只做 |
|---|---|---|
| D1、D2 表单 | 从立项信息、产品配置、同类模板预填 | 补空白项、签署 |
| 调研包 | 按角色选题、资料预填，一键批量发布 | 只看改过的题 |
| 客户自评 | 生成自评包与邮件正文；到期前一天、当天提醒，逾期 2 天升级项目经理；校验全过直接入池 | 发邮件、告知口令、导入时输入口令 |
| 访谈 | 算最晚访谈日、生成议程、现场实时提示、催办话术 | 约人、访谈、矛盾现场定案 |
| 事实确认 | 多来源一致的，以及单一高可信来源（客户资料、现场证据）的自动确认，按比例抽检 | 矛盾、只有客户自评或现场口述的、关键控制项 |
| 证据不足 | 相关角色还没访谈的，自动放进其现场议程 | 没有渠道可补时才出确认卡 |
| D3 | 门禁 0 问题且每条可追溯到证据 → 核对与签署合并 | 项目经理批量签；有门禁问题回到逐条核对 |
| 发现表 | 依据全是已确认事实、规则打分明确的自动确认 | 低置信、有矛盾未决的 |
| 交付件修订 | 机械问题自动修（≤ 2 轮）；客户意见自动拆条对章节；上游变更一键修订 | 内容取舍、签署 |
| 阶段推进 | 关口条件满足自动进入下一阶段，生成阶段包与汇报 PPT 草稿 | 审汇报、签署 |
| 简报、待办 | 每周五自动生成本周简报进项目经理待办；我的任务跨项目按卡点影响面、截止日、离签署步数排序 | 改两句发客户 |
| 质量保险 | 自动化账本（自动 / 人工 / 抽检差错）；自适应抽检：发现差错该类自动收紧、退回人工，连续无差错再放开 | 看账本异常 |

全景默认“只显示例外”，已自动办完的折叠为“本周自动完成 N 项”。

仍由人做且不自动化：签署；对客户发邮件、约访谈；输入自评答卷口令；现场访谈与矛盾定案；低置信发现与方案取舍；删除确认（双人）。
