需要人工留意的几处：
- **操作风险管理办法**：只收正文第一至五十二条，文末“附录：名词解释及示例”未收。附录里有以“第七条、第九条……”开头的句子，按条切会被误认成条款。
- **业务连续性监管指引**：国家金融监督管理总局官网没有可直接取的原文，用的是上海市发展改革委网站转载的 PDF。原文没有文号，文号按原银监会发文补写。审核时请核对现行状态。
- **银行保险机构数据安全管理办法**：附件“数据安全事件分级”是表格，没有收。

还没有收的：
- 电力监控系统安全防护配套方案（国能安全〔2015〕36号，在核实是否随 27 号令更新）
- 商业银行信息科技风险管理指引
- JR/T 0071、0197、0223 等金融行业标准：标准只收条款目录，放 batch6
