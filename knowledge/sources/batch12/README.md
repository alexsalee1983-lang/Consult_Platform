## 需要人工留意

- 两份指南是 docx 原件原样保留，无文号，所以 kb-source-split 的核验“写了文号”一项不过，会转人工审核。
- 两份指南的第四项“咨询、举报联系方式”含电子邮箱，被机密级检测退回（_rejected），属公开联系方式，不入库即可。
- 个人信息出境标准合同备案指南（第二版）：附件里的承诺书续用“五、”编号，切出的第 5 项（src-ed7ed48e-5）其实是承诺书加整份标准合同，不是指南正文，建议审核时剔除。第三版没有这个问题。
- 国家网络安全事件应急预案：编号体系是“1 总则、1.1 …”，只能用按章节切分。网页正文开头的“目 录”块（44 行，只是目录）已从 txt 删除，否则目录行会占掉章节首次出现位置、正文落空。除此之外没改任何文字。
- 应急预案的发布日期取落款 2017-01-10（网站挂网日 2017-06-27），施行日期按“印发之日起”也记 2017-01-10。两份指南的施行日期按发布日填，官网未另写。
- 网信部门行政执法程序规定取自 cac.gov.cn 正文页（含令号页头），日期 2023-03-23 为公布日。
- 个人信息出境标准合同备案指南官网最新仍是第二版，没有第三版。第二版申报指南已被第三版替代，未收。
- 1960号指导意见：mps.gov.cn 对脚本访问有 JS 校验（没有绕过），由负责人 11-16 在浏览器打印成 PDF（入库目录里的 .pdf，网页原件sha256 记的是它）。PDF 里的文字是图形，提取不出，txt 是对照 PDF 逐页人工转录（经模型），所以清单 sha256 列故意留空，核验不过、转两项人工审核：审核人须逐项对照 PDF 核对文字。官网页面没有写文号，文号公网安〔2020〕1960号取自公开转载，审核时一并确认。
- 已收清单里已有：网络安全审查办法、个人信息保护合规审计管理办法、国家网络安全事件报告管理办法，没有重复下载。
