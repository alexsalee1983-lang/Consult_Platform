## 需要人工留意

- **原网址白名单**：dspdp.gov.mo、chinhphu.vn 等域名要在 `KB_SOURCE_HOSTS` 里才能自动核验；ratchakitcha.soc.go.th 不在白名单里，预期转人工审核。
- **整理件（澳门、泰国）**：清单 sha256 列故意留空，核验不过、转两项人工审核，审核人对照同目录的 PDF 核对文字；“网页原件sha256”记的是 PDF 的哈希。
  - **澳门**：公报页是中葡双语交错排版，直接切会把葡文和中文混在一起、条文错位。txt 只保留含汉字的行，去掉葡文行、每页页眉，以及前一部法律在本页的尾部（从“第 8/2005 號法律”起）。PDF 打了权限密码（空口令可打开），目录里的是下载原件（sha 即“网页原件sha256”）。法律日期：2005-08-04 通过，2005-08-22 刊登公报；第 46 条“公佈後一百八十日起生效”，施行日期按 2006-02-18 填，请核对。附表、第 3 条等无需处理。
  - **泰国**：PDF 提取的泰文有两类机械问题，只改了这两类：① 元音“ำ”被拆成“空格+า”（806 处，如“จ ากัด”改为“จำกัด”），② 每页页眉（“หน้า … / เล่ม ๑๓๖ ตอนที่ ๖๙ ก / ราชกิจจานุเบกษา / 日期”共 44 页 88 行，顺序还是乱的）去掉；另去掉每行行尾空白。个别词中间仍夹空格（如“ส่ว นบุคคล”），没动。切分器已支持泰文数字，不需改代码。
  - 泰国公报原文不含后续修订。第 2 条规定主要章节在公布满一年后施行，后来又多次延期，实际全面施行日期（2022-06-01）请核对后再改清单；清单施行日期现填公布次日 2019-05-28。
- **越南 91/2025/QH15**：batch11 记过官方 PDF 是扫描件，这次的公报 CDN 版本带文字层。施行日期 2026-01-01。
- **越南网络安全法**：公报原文，未含 2025 年以后可能的修订；施行 2019-01-01。
- 各份条文里的附表、签署页（如有）可能并入末条。审核时对照 PDF。
