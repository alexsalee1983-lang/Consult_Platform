# 公开资料原文（内容线 · 开发线 2）

按批次存放从官方网站下载的**法律、行政法规**原文和下载清单（`manifest.csv`，列见 `backend/app/kb/sources.py`）。
法律、行政法规不受著作权保护，原文可入库；**国家标准、行业标准不放原文**，只收条款号、标题、解读和映射（决策记录）。

| 批次 | 内容 | 份数 / 条数 | 来源 |
|---|---|---|---|
| batch1 | 网络安全、数据、个人信息、密码、关基、国家安全、保密、反间谍、反诈、电子签名法律法规（现行版） | 12 份 / 742 条 | 国家法律法规数据库 flk.npc.gov.cn |
| batch2 | 部门规章：网络安全审查、数据出境评估、标准合同、数据跨境流动、个人信息保护合规审计、网络安全事件报告、商用密码应用安全性评估、电力监控系统安全防护、银行保险机构数据安全、人民银行业务领域数据安全 | 10 份 / 299 条 | 网信办、密码局、中国政府网、金融监管总局、人民银行官网 |
| batch3 | 附件：网络安全事件分级指南、个人信息保护合规审计指引；行业：证券期货业网络和信息安全管理办法（证监会令第218号）、电力行业网络安全管理办法（国能发安全规〔2022〕100号）、电力行业网络安全等级保护管理办法（101号） | 5 份 / 169 条 | 网信办官网、中国政府网 |

文号已对照官方公布逐份核对；`sha256` 为切条所用文件的哈希。

batch2 官网只发网页的，开发侧只取网页正文容器机械转成 .txt（不改字；“附件”及之后的分级指南、审计指引、合同范本另行处理，不并进最后一条），
清单另列 `网页原件sha256` 供对照。国家网络安全事件报告管理办法官网未标令号，核验“文号”一项不过、转人工审核（如实反映，不编号）。导入（测试机后端容器内）：

```bash
python -m app.cli kb-source-split /srv/knowledge/sources/batch1/manifest.csv --dir /srv/knowledge/sources/batch1 --out /tmp/batch1
python -m app.cli kb-source-publish /tmp/batch1 --as <知识专家>   # 平台核验 + 5% 抽检（B10，决策记录 2026-11-15）
```


batch3 是 batch2 两个网页里“附件”之后的正文，开发侧同样机械转成 .txt（只取附件名称行到网页页脚之前），切分方式“按项”（`item`，#129）：
按“一、二、三”切、项号连续，“（一）”“1.”留在本项正文。事件分级指南同母办法没有文号，核验 code 不过、转人工审核。

```bash
python -m app.cli kb-source-split knowledge/sources/batch3/manifest.csv --dir knowledge/sources/batch3 --out /tmp/batch3-out
```

batch3 行业文件：证监会令第218号取中国政府网转载的官方 PDF（页码由切条去掉，#129）；能源局 100 号、101 号中国政府网只发 .doc，
开发侧用 Word 另存为 .docx（100 号条号是 Word 自动编号，另存前先“编号转文字”），`网页原件sha256` 列记原 .doc 的哈希。
两份能源局文件“自发布之日起施行，有效期5年”（至 2027-11），季度核对（B5）时留意续期或替代。
