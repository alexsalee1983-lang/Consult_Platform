# 虚拟客户素材（二期 D 线 ⑤）

四个新产品各一套虚拟客户素材，用于测试环境端到端验收（`docs/acceptance/d5-产品端到端验收.md`）。全部虚构，客户只用虚拟代号；不含口令、密钥、IP、完整拓扑、漏洞利用细节、业务数据或个人信息样本（`tests/test_virtual_clients.py` 逐个文件过机密级检测）。

| 目录 | 产品 | 虚拟客户 | 档位 | 行业 |
|---|---|---|---|---|
| ire/ | IRE 事件后 E2E 评估与整改 | MFG-C | 标准档 | 制造 |
| dsm/ | DSM 数据安全管理体系 | BANK-A | 标准档 | 银行 |
| iso/ | ISO ISO 27001 认证咨询 | GRID-B | 标准档 | 电力 |
| nsg/ | NSG 网络安全治理规划 | MFG-C | 标准档 | 制造 |

每套：`notes-*.md` 是访谈纪要（录成 I-xx，只写受访者角色），`doc-*.txt` 是客户资料（上传成 D-xx），`obs-*.md` 是现场观察（录成 O-xx）。
