三级系统远程管理须采用两种以上组合鉴别技术

已发布 v3控制项解读金融 · 能源电力 · 制造复审到期 2027-02-10
用于差距分析与整改建议；不构成测评结论

正文与适用范围

适用于等级保护第三级及以上系统的管理员远程登录（含运维堡垒机、云管平台控制台）。要求同时使用两种或两种以上组合鉴别技术，其中至少一种应基于密码技术[1]。

差距分析时常见情形：仅口令 + 图形验证码（不满足）；口令 + 短信验证码（满足组合，但需评估短信通道风险）；口令 + 硬件令牌或 OTP（满足）[2]。

整改建议优先级：远程运维入口先于本地控制台；与密码应用改造合并实施可降低成本。

改版全景

原则：自动化优先——机器跑全流程，人只处理例外与必须担责的事

① 顾问 · 用知识

知识检索、投料箱保留；对话与交付件里的引用角标、检索结果统一跳条目详情；新增一键反馈（有误 · 过时 · 缺了）

② 知识专家 · 只处理例外

审批队列 + 专家工作台合成「待我处理」：问答卡片、影响排序、批量决定、明天再看、每日时间预算；入口同时挂「我的任务」和飞书提醒，专家全程不碰命令行

③ 知识管理员 · 看运转

流水线（新增）、来源登记（补派生条目与采集结果）、健康（地图 + 使用统计 + 就绪度三合一，新增自动发布抽检与信任度）

闭环 A · 补缺口

  3. 自动出采集包 → 流水线
  4. 发布后红格自动变绿

闭环 B · 法规变更

  1. 来源变更，自动比对差异
  2. 影响分析：条目、映射、在办项目
  3. Agent 预复核
  4. 有疑问的进专家收件箱
  5. 修订发布，通知相关项目经理

闭环 C · 使用反馈

  1. 引用处 / 条目详情一键反馈
  2. 专家卡片裁决
  3. 修订发布
  4. 引用数、反馈数回健康页

闭环 D · 信任度自调

  1. 自动发布按类型抽样
  2. 专家抽检
  3. 错误率高 → 收紧自动发布
  4. 持续合格 → 放宽、降抽检比例
